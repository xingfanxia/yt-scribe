### Description (English)

Scribe turns the captions of a YouTube or Bilibili video into text you can copy, export or talk to.

COPY IN ONE CLICK
• Copy the transcript from the toolbar popup, from a button under the video, or with Cmd/Ctrl+Shift+Y.
• Choose timestamps, title, link, line spacing or a single paragraph, and see a live preview.
• Pick the caption language right next to the preview. Manual captions are preferred over auto-generated ones.
• Optionally start the text with your own AI prompt and open Claude, ChatGPT, Gemini or Perplexity after copying.

EXPORT
• Text, Markdown or PDF. PDFs download directly with selectable text, including Chinese and Japanese.

CHAT WITH THE VIDEO
• Open the side panel and ask anything, or use ready-made actions: summary, key takeaways, quotes, flashcards, quiz, simple explanation, claims, cited summary, open questions, social thread, blog outline, chapters and translation.
• Every [m:ss] in an answer is a link that jumps the video to that moment.
• Uses your own Anthropic API key, or any OpenAI-compatible endpoint. Requests go straight from your browser to that provider.

ALSO
• Named presets for output formats, a searchable history of transcripts and chats, English and Chinese interface.
• Bilibili subtitles require being signed in to bilibili.com, as Bilibili only serves them to signed-in users.

PRIVACY
No account, no tracking, no server of our own. Settings and history stay in your browser. Open source (MIT): https://github.com/xingfanxia/yt-scribe

Scribe is not affiliated with YouTube, Google or Bilibili.

## Privacy practices tab

**Single purpose:** Get the transcript of the YouTube or Bilibili video being watched, and copy, export or discuss it with an AI model chosen by the user.

**Permission justifications**

| Permission | Justification |
|---|---|
| `storage` | Saves the user's format settings, presets, history and AI provider settings. |
| `unlimitedStorage` | History stores full transcripts (up to 500 videos) so "Copy again" and saved chats work without refetching; this can exceed the default quota. |
| `scripting` | Injects the transcript script into a YouTube/Bilibili tab opened before the extension was installed, and reads the page's own player data (caption track list) in the page context. |
| `sidePanel` | The AI chat about the current video runs in Chrome's side panel. |
| `activeTab` | Acts on the current tab when the user clicks the toolbar button or uses a keyboard shortcut. |
| `tabs` | Reads the active tab's URL and title to know which video is open, follows video changes for the side panel, and opens the video or AI site the user asks for. |
| `clipboardWrite` | Copies the transcript or chat to the clipboard when the user asks. |
| Host `www.youtube.com`, `m.youtube.com`, `www.bilibili.com` | Reads caption tracks and adds the optional Copy/Ask AI buttons on video pages. |
| Host `api.anthropic.com` | Sends the user's chat messages with the transcript to Anthropic when the user chats, using the user's own key. |
| Optional host `https://*/*`, `http://*/*` | Requested only when the user configures a custom OpenAI-compatible endpoint, and only for that endpoint's origin. |

**Remote code:** No. All JavaScript, including the bundled pdfkit library, ships in the package.

**Data usage** (check these boxes):

- Website content — the video's transcript and title are sent to the user-selected AI provider when the user chats.
- Authentication information — the user's own AI API key is stored locally and sent only to that provider.

Not collected: personally identifiable information, health, financial, personal communications, location, web history, user activity.

Certify all three: not sold to third parties; not used or transferred for purposes unrelated to the single purpose; not used to determine creditworthiness or for lending.
